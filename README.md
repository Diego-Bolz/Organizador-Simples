# Organizador-Simples
- Um organizador de arquivos simples que organiza a pasta downloads em sub pastas.
# Como Utilizar
- Apenas rode o módulo, e ele fará o resto.
- Sub pastas: Audío e Vídeo, Compactados, Documentos e Textos, Imagens, Outros
- O algoritmo reconhece arquivos: pdf, docx, txt, xlsx, jpg, jpeg, png, gif, mp3, wav, mp4, mkv, avi, zip, rar e exe
# Ferramentas Usadas
- Vscode
- Python 3
- Bibliotecas: os e shutil
